# Stress-Level Classification with Artificial Neural Networks

This project explores classification of stress levels using job-related information, mental-health awareness, and health-history records.

## Included material

- `Makalah Sains Data (1).pdf` — project paper documenting the approach, analysis, and findings.

## Purpose

This is an educational data-science project. Any model discussed in the report is not a medical diagnostic tool and should not be used to make healthcare decisions.
