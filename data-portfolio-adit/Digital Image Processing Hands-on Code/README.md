# Digital Image Processing: Frequency-Domain Filtering

Hands-on Python work exploring frequency-domain filtering techniques from *Digital Image Processing* by Rafael C. Gonzalez and Richard E. Woods.

## Contents

- `Filtering_in_the_Frequency_Domain_Kelompok_3_TK1_Citra_Digital.ipynb` — notebook containing the implementations and experiments.

## Run locally

Open the notebook with Jupyter or Google Colab. Install the dependencies required by its import cells, then run it from top to bottom.

```bash
pip install jupyter numpy matplotlib opencv-python
```

## Scope

The notebook is intended as an educational implementation of frequency-domain image-processing concepts. Refer to the notebook cells for the input-image requirements and experiment details.
